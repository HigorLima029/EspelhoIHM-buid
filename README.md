# Espelho IHM Chen Hsong — gerar o .exe (Windows) sem precisar de PC Windows

1. Crie um repositorio novo no GitHub (pode ser privado).
2. Suba estes dois arquivos mantendo as pastas:
   - `espelho_ihm.py`
   - `.github/workflows/build.yml`
3. Vá na aba **Actions** do repositorio. O build roda sozinho (ou clique em
   "build-exe" > "Run workflow").
4. Ao terminar (uns 2 min), abra a execucao e baixe o artefato
   **EspelhoIHM-windows** — dentro dele esta o `EspelhoIHM.exe`.
5. Envie o `EspelhoIHM.exe` para o PC do operador. Dois cliques e abre.
